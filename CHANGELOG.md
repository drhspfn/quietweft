# Changelog

## 1.4.4

First public Quietweft release, following private development.

- Compact local microphone processor with device routing and an On/Off switch.
- Pinned GTCRN DNS3 model, included locally rather than downloaded on startup.
- Native Rust CLI and C embedding interface.
- Training, export, build and measurement documentation.
- Audio/video examples with source and processing details.

This release does not claim universal suppression quality or certified
end-to-end microphone latency. Examples and timing measurements have different
purposes and are documented separately.

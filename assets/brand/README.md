# Quietweft artwork

`mark.png` is the project mark: two sound-wave ribbons forming a lowercase q.
The original raster artwork was generated for Quietweft and is distributed
under the project's MIT license. Desktop icon sizes are produced from this
master by Tauri's icon converter.

Quietweft uses midnight ink, sky blue and ivory. The wordmark is rendered as
text, not embedded in the icon. Do not imply endorsement by the GTCRN authors.
